FLIQ V2: SHADOW ARCADE - MASTER DOCUMENTATION
===========================================

1. PROJECT VISION: "SHADOW ARCADE"
----------------------------------
Fliq v2 is a high-intensity, competitive arcade game designed to blend kinetic
reflex tapping with cognitive memory tasks. The goal is to move beyond a simple
utility app into a polished, addictive gaming experience.

CORE PILLARS:
- Action: High-speed, rhythmic gameplay with instant feedback.
- Reward: Progressive leveling system (XP) and a virtual economy (Coins).
- Growth: 100+ level campaign across themed "Worlds."
- Competition: Global rankings and social "Brag Card" sharing.


2. VISUAL THEME & UX VISION
---------------------------
THEME: "SHADOW ARCADE" (Premium Dark Mode)
- Background: Obsidian Midnight (#020617). Deep, layered black.
- Surfaces: "Smoke Glass." Frosted, semi-translucent panels over animated backgrounds.
- Lighting: Neon Glows. Electric Cyan (Progress/Safe) vs. Pulse Magenta (Memory).
- Materials: Physical depth, Z-axis scaling, and dynamic shadows.

UX VISION: "THE KINETIC FLOW"
- Continuous Transitions: Camera-zoom transitions instead of loading screens.
- Zero Friction: The "Play" button is always the primary thumb-centric action.
- Tactile Feedback: Custom haptics (Sharp Pulse for hits, Impact Rumble for fails).


3. CHALLENGE CLASSES (GAME MODES)
---------------------------------
CLASS A: REFLEX (The Classic Blitz)
- Mechanic: Pop coins, avoid bombs.
- v2 Twist: Fever Mode (2x points), Shielded Coins (Multi-tap), and Shrinking Tiles.

CLASS B: MEMORY (The Recall)
- Mechanic: Watch a sequence, then repeat it from memory.
- Variations: Flash Recall (simultaneous), Mirrors, and Decoys (fake tiles).

CLASS C: TRACE (The Flow)
- Mechanic: Swipe through a path of coins without lifting your finger.
- Variations: Moving Paths (sliding lines) and Winding Mazes.

CLASS D: HYBRID (Boss Stages)
- Mechanic: Dual-tasking. Memorize a pattern on top while tapping coins on the bottom.

5. THE DOPAMINE ECONOMY (XP & COINS)
------------------------------------
PROGRESSION:
- Star 1 (Clear): Completion of primary objective.
- Star 2 (Elite): Secondary precision/combo threshold met.
- Star 3 (Master): Top-tier speed or high-streak goal met.
- Unlocking: Stages are unlocked sequentially. Stage 20 clear unlocks World 2.

CURRENCY (Neuro-Credits):
- Shop: Spend on Coin Skins (Molten, Cyber, Chrome).
- Loadouts: Spend on one-time Boosts before a match starts.

BOOSTS:
- Shield (100 🪙): Absorbs the first bomb hit or missed coin.
- Slow-Mo (150 🪙): Coins stay 20% longer on screen.
- Double XP (200 🪙): Multiplies the final match XP total by 2x.


6. REWARD SYSTEM & SOCIAL LOOP
------------------------------
PLAYER CARD (The Brag Card):
- Sleek, shareable visual showing Avatar, Level, Rank, and Star breakdown.
- Skill Radar: Hexagon chart showing Speed, Memory, Focus, Swiping, and Precision.

SOCIAL SHARING:
- One-tap share to Instagram, WhatsApp, and Twitter.
- Deep-link integration: Friends can tap shared cards to jump directly to that stage.


7. TECHNICAL ARCHITECTURE (v2 ENGINE)
-------------------------------------
STATE MACHINE:
1. BRIEFING: Load goals and loadouts.
2. COUNTDOWN: Prepare player.
3. PREVIEW: (Memory Only) Show the target pattern.
4. ACTION: Core gameplay loop (Tapping/Swiping).
5. FEVER: Bonus high-intensity streak mode.
6. FALLOUT: Post-game Matrix effect transition.
7. VAULT: Animated results and rewards.

ENGINE SPECS:
- Unified Controller: One engine handles all classes via a injected Stage Blueprint.
- Offline-First: Local Room persistence with background Firebase sync.
- Reactive UI: Full Jetpack Compose state-driven rendering.
- Modern Navigation: Continuous flow via navigation-compose.
